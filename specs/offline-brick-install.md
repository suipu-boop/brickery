# 离线积木安装（积木包导入通道）

> 状态：规划中（活文档，可随时补充）
> 关联：specs/skill-repo-github-only.md（市场源已改为 GitHub Only）

## 背景与动机

市场源改为「GitHub Only」后，正式安装包不再携带离线市场源。这带来一个缺口：
**用户电脑没网时，无法从市场拉取任何积木**——首次开箱无网即空市场。

目标人群：无网/弱网/内网环境的用户，或只想要某几块积木、不想整包下载的用户。

## 两种安装方式（已确认）

| 方式 | 途径 | 适用场景 |
|------|------|----------|
| 联网安装 | 底座自带积木市场，直接从 GitHub 拉取安装 | 有网电脑 |
| 离线导入 | 有网设备下载 .brick → 传到本机 → 拖入导入 | 无网 / 纯本地模型运行电脑 |

两种方式装出来的积木在本地存储、运行上完全一致，只是获取途径不同。

## 用户旅程（离线导入）

1. 用户在有网设备打开工坊（或网页市场），点积木卡片「下载 .brick」按钮
2. 文件下载到**桌面**（默认路径，小白找得到）
3. 通过 U 盘 / 微信 / 网盘把 .brick 弄到目标电脑（可一次带多个）
4. 打开底座的积木市场页，把 .brick 文件**拖进导入区**（或点按钮多选文件）
5. 智能体校验 → 批量安装 → 市场页出现该积木，标记"已安装（离线）"

## 积木包格式 `.brick`（已定：zip）

单个 zip 包，扩展名 `.brick`。选 zip 的理由：

- Python 标准库 `zipfile` 直接处理，无额外依赖
- 积木天然多文件结构（指令 + 资源，未来可带图标/脚本/模型），zip 可扩展
- 压缩率好；JSON+base64 单文件在资源变大时膨胀 33%
- 对小白无感知差异——都是"拿到一个文件拖进去"

结构：

```
hello-brick-1.2.3.brick
├── manifest.json          # 必需：积木元信息
├── skill/                 # 必需：积木指令目录（与市场源同构）
│   ├── SKILL.md
│   └── resources/...
└── assets/                # 可选：脚本/图标/数据等附属资源
```

`manifest.json` 字段（与市场 index 条目对齐）：

```json
{
  "id": "hello-brick",
  "name": "Hello 积木",
  "version": "1.2.3",
  "author": "suipu-boop",
  "summary": "打招呼示例积木",
  "category": "demo",
  "tags": ["hello"],
  "sha256": "包内 skill/ 目录内容哈希（防篡改）",
  "source": "offline"
}
```

## 下载侧（工坊页 + 网页市场，已确认）

- 工坊市场页、网页市场页均加「下载 .brick」按钮
- 下载路径默认 **桌面**（小白友好，不弹复杂保存框）
- 服务端按积木 id 从 GitHub 源拉取对应 skill 目录，实时组装 zip 返回
- **批量打包（已确认）**：工坊市场页支持勾选多块积木，点「批量下载」打包成一个 .brick 文件（内含多块积木），存到桌面

## 智能体侧导入（小白化，已确认）

新增 IPC 接口 `skill_library_import`（ipc.py 注册）：

- 入参：一个或多个本地 .brick 文件路径
- 流程：
  1. 校验扩展名 .brick + zip 结构合法
  2. 读 manifest.json，校验 sha256（防篡改/防损坏）
  3. 解压到本地积木根目录 `home/skills/<id>/`（与市场 install 落点一致）
  4. 逐个返回结果：id / name / version / 成功或失败原因
- **批量导入**：支持一次拖多个 .brick / 多选文件 / 传入文件夹（文件夹内所有 .brick 递归导入）
- 兼容性：单包内含多块积木（批量打包产物）也能一次导入全部

## UI 形态（底座市场页内修改，已确认）

在 chat_ui.py 积木市场页做以下小白化改造：

1. **导入入口**：市场页顶部显眼的「导入积木包」按钮 + 虚线拖拽区
   - 支持把 .brick 直接拖进窗口/市场页
   - 支持点击按钮弹 macOS 文件选择器（可多选）
2. **直白使用说明**（文案定稿）：市场页顶部常驻一行提示：
   > **没网也能装积木：在工坊或网页点「下载 .brick」，把文件拖到这里，或点按钮选择文件。可一次拖多个。**
3. **导入确认弹窗（已定：专用弹窗）**：
   - 自绘弹窗（不用系统原生 confirm，信息展示不了）
   - 标题：「导入积木」
   - 内容：积木名称、版本、作者、简介；非官方来源显示"来源未知"标记
   - 按钮：「安装」/「取消」
   - 批量导入时：确认弹窗列出全部待装积木，用户一次确认
4. **导入结果反馈**：逐块积木卡片显示 成功（名称/版本/已安装）或 失败（原因），失败可重试
5. **已装状态**：离线导入的积木与联网安装的一样，显示"已安装"，可卸载、可禁用
6. **批量下载提示**（工坊页，文案定稿）：
   > **勾选多块积木后点「批量下载」，会打包成一个 .brick 文件存到桌面**

## SkillLibrary 合并展示改造

`list_entries` / 市场列表合并逻辑：

- 本地已装积木（含离线导入）始终出现在市场列表，标记 `installed: true`
- 远程市场与本地按 `id` 对齐：
  - 本地有、远程无（离线导入/已下架）→ 显示"已安装（离线）"，可卸载
  - 两边都有 → 显示已装版本，远程版本更高时提示"可升级"（联网时）
  - 本地无、远程有 → 正常"安装"按钮
- `market_installed()` 直接读本地目录，离线可用

## 安全

- **哈希校验**：导入时校验 manifest.sha256 与包内容一致，不符拒绝安装
- **来源提示**：导入确认弹窗显示作者/版本/摘要，非官方源标记"来源未知"
- **可卸载**：导入的积木与市场安装一样可卸载、可禁用，不留残余
- 积木本质是代码：导入即执行能力授予，UI 必须给明确确认（专用确认弹窗）

## 影响与兼容

- 不影响 GitHub Only 市场源解析
- 安装包体积不变（不随包带离线源）
- 旧版本 config 无影响；本地积木目录结构复用现有 `skills_registry` 落点
- 离线导入的积木不参与远程市场升级对比（除非 id 与远程一致）
