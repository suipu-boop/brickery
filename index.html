离线安装引导

把 .brick 积木包装进你已生成好的 agent（底座），全程无需联网到市场。

1
下载积木包
在市场点「下载 .brick」获取单块或批量积木包。
2
安装 agent
在目标机上安装用积木工坊生成好的 agent 应用（若已安装可跳过）。
3
导入积木包
打开 agent，把 .brick 文件拖入聊天窗口（或使用菜单导入），即完成安装。
